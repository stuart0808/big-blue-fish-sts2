# 蓝色大肥鱼 · 重设计方案 v2：干饭 · 摸鱼 · 刷屏

> 状态：方案稿，未实现。确认后再改代码和卡牌。
> 依据：自动测试的数据，以及网上对「DeepSeek 鲸鱼娘 / 大肥鱼」形象的调研（来源见文末）。

---

## 0. 为什么要重做

| 问题 | 现状 |
|---|---|
| 核心机制没特色 | 「深度」本质上是可以花掉的力量。每回合的决策几乎固定：先叠深度，再打鲸跃。 |
| 流派像原版 | 深潜 ≈ 铁甲力量流，思考 ≈ 保留牌，幻觉 ≈ 静默的小刀；换气流本来最有特色，但联动牌太少，鲸跃还有 bug。 |
| 人设只停在卡名上 | AI 术语都挂在普通效果上；最出圈的生活梗（吃白饭、摸鱼、讨 Token、拒绝被叫胖、评论区刷屏）一个都没用。 |
| 数值偏弱 | 普通攻击牌每费约 7 伤害，原版是 8–10。 |

**v2 的目标**：做一套「只有大肥鱼有」的核心节奏，让人设长在机制上。

- 原版角色都是「每回合把能量花光」。大肥鱼反过来：**会摸鱼、攒饭，吃饱了再一口气开工**。
- 玩家一眼就能认出梗，打起来又有真正的取舍：这回合摸鱼攒饭，还是现在就打？

## 1. 人设 → 机制对照

| 网上的人设 | 机制 |
|---|---|
| 爱吃白饭，「回家吃白饭」 | **饱腹**：核心资源，「吃白饭」获得 |
| 吃饱了才肯干活 | **开工**：消耗饱腹，换成伤害、格挡等爆发；**吃饱**状态下很多牌更强 |
| 爱摸鱼，「我去吃饭，测完告诉我」 | **摸鱼**：回合结束时还有没花完的能量，就会触发收益 |
| 聪明但懒，深度思考 | **思考**：留在手里过回合就升级（沿用 v1） |
| 评论区挤满大肥鱼 | **刷屏**：生成「评论」衍生牌，评论越多越强（取代 v1 的幻觉） |
| 自称「大肥鱼」，却绝对不许别人叫胖 | **恼羞成怒**：被上负面效果、被打穿格挡就攒怒气，下一击爆发 |

| 峰谷定价，高峰时段价格翻倍 | 稀有能力「峰谷定价」：奇数回合贵但更强，偶数回合打折 |
| 讨要 Token | 刷屏流的启动牌，评论够多时给能量 |
| 女仆装，服从主人，叫用户「鱼片」 | 联机牌：照顾队友（「主人」） |
| 服务器繁忙，鲸鱼又崩了 | 沿用 v1：R1 满血版、宕机重启、服务器繁忙 |
| 清除插件小游戏里的「白饭加特林」 | 干饭流的群伤牌 |

深海 / 下潜不再作为核心机制。鲸鱼的身份保留在美术、角色台词和一部分卡名里（鲸脂、鲸吞、本鲸）。v1 的三套规则（深度、水压、上浮）一次性换成一套更直观的「饱腹」。

## 2. 核心规则

### 2.1 饱腹（能力，显示在角色身上）

- 范围 0–10，跨回合保留，战斗结束清零。
- **吃白饭 X**：饱腹 +X。超过 10 的部分不浪费：**每溢出 1 点获得 2 点格挡**（「这不是胖，是鲸脂」）。
- **吃饱**：饱腹 ≥ 6 时处于「吃饱」状态。牌面写「吃饱时：……」的效果在此时生效。
- **开工 X**：消耗至多 X 点饱腹，按实际消耗的点数结算效果。「开工 全部」消耗全部饱腹。

### 2.2 摸鱼（角色特性，由初始遗物提供）

- 初始遗物 **电饭煲**：战斗开始时吃白饭 2；**回合结束时，每有 1 点未使用的能量，吃白饭 2**。
- 牌面写「摸鱼：……」的效果，只在**回合结束时还有未使用的能量**时触发（这张牌在手里，或者对应的能力在场）。
- 数值锚点：1 点能量直接打出 ≈ 8–9 伤害；摸鱼省下 1 点能量 → 2 饱腹 → 开工时约 6 伤害。单看不划算，所以摸鱼是**看局面的选择**：在敌人不攻击的回合、或者手牌不好时摸鱼，配合摸鱼牌和吃饱加成才赚。

### 2.3 评论（衍生牌，取代 v1 的「幻觉」）

- **评论**：0 费，虚无，消耗。对随机敌人造成 2 点伤害；**手牌中每有 1 张其他评论，伤害 +1**。
- **刷屏 X**：将 X 张评论加入手牌（手牌满时进弃牌堆）。

### 2.4 恼羞成怒（能力）

- 下一张攻击牌额外造成「层数 × 3」点伤害，然后清零。
- 获得方式：卡牌，以及「本鲸生气了」等能力（被施加负面效果、受到未格挡伤害时获得）。

### 2.5 沿用的关键词

- **思考**（沿用 v1）：保留；回合结束时如果还在手里，就在本场战斗中升级。
- **服务器繁忙**（状态牌，沿用 v1）：不能打出，虚无。

## 6. 数值与平衡

- **整体上调一档**：普通 1 费攻击 8–9 伤害、格挡 7 左右，向原版看齐，解决 v1 前期打不动的问题。
- **饱腹的价值**：1 点饱腹在开工时约值 3 点伤害；吃饱加成按「多 30%–50%」设计。
- **摸鱼不能强制最优**：摸鱼 1 点能量的直接回报（2 饱腹 ≈ 6 伤害）要低于直接打出（8–9 伤害），收益来自摸鱼牌和吃饱加成。这样「摸不摸」才是真正的决策。
- **满血版**：沿用现在的做法，在 v2 数值上再 ×1.5，定位不变。
- **验证方法**：用现成的自动测试，和 5 个原版角色在进阶 0 比较：
  - 胜率、平均每回合伤害、进 Boss 时的血量。
  - **特色指标**：有多少回合是「主动留能量摸鱼」或「开工爆发」。如果这两类回合很少，说明机制没被用起来。
